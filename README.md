Ce mini-site sert uniquement de porte d'entrée vers le Planning Apps Script.
Il permet à Safari/iOS de voir une vraie balise apple-touch-icon.

À héberger tel quel sur un hébergeur statique HTTPS (GitHub Pages, Cloudflare Pages, Netlify, etc.).
Ensuite:
1. ouvrir l'adresse du mini-site dans Safari sur l'iPhone;
2. Partager;
3. Ajouter à l'écran d'accueil;
4. supprimer l'ancien raccourci gris « P ».

Le mini-site redirige automatiquement vers l'application Planning existante.
